## About

- Full-stack engineer who ships complete products — UI, API routes, database schema, and smart contracts when the product calls for it.
- Currently building daily on-chain competition apps on **Celo**, designed **MiniPay-first**: embedded wallets, stablecoin payments, idempotent settlement.
- Background in data work — SQL, Python, Power BI, Pandas — for analysis, reporting, and automation.
- I care about the boring-but-critical parts: idempotent payments, retries, migrations, and not breaking things when real money is involved.

## Featured Projects

### 🐝 Avíspate
Daily visual-agility game on Celo. Two cards always share exactly one symbol — spot it faster than the rest of the deck; the fastest player of the day splits that deck's USDT pool. Built MiniPay-first, with a verified on-chain contract (`AvispatePot`) that gates free daily plays and settles payouts.

**[avispate.fun](https://avispate.fun)** · [source](https://github.com/JuanFCast/avispate-visual)

### ⌨️ TypeRush
Daily typing competition built for MiniPay. Pay a small stablecoin entry, race a 45-second prompt, get scored on WPM and accuracy, and the top typer takes the day's pool. Entry, pool, and payout run through a multi-currency Solidity contract on Celo Sepolia.

**[typerush.fun](https://typerush.fun)** · [source](https://github.com/JuanFCast/TypeRush)

### 🎓 BIntuitive
Touch-first educational game for young learners, iPad-first and responsive down to phones. Five bilingual mini-games with adaptive difficulty and spoken instructions (Web Speech API). Reuses the core mechanics from Avíspate and TypeRush, stripped down to a privacy-friendly, backend-free MVP — no wallets, accounts, payments, or blockchain.

**[bintuitive.aumcrsp.com](https://bintuitive.aumcrsp.com)** · [source](https://github.com/JuanFCast/BIntuitive)

## Areas of Experience

- **Full-stack development** — Next.js/React frontends wired to Node.js/PostgreSQL backends, deployed on Vercel.
- **Web3 on Celo** — wallet integration (Privy embedded wallets, RainbowKit/wagmi), Solidity contracts with Hardhat, MiniPay-specific UX (stablecoin fees, no gas exposed to the user).
- **Data & automation** — SQL and Python for analysis, Power BI/Pandas for reporting, cron-driven jobs for scheduled settlement and payouts.
- **Product ownership** — comfortable owning a feature end to end, from database schema to smart contract to deployed UI.
